# AI PM Fieldkit

Eight editable AI product management templates and fictional worked examples. Static HTML, CSS, and JavaScript.

## Run locally

Use python3 -m http.server 8000 and open http://localhost:8000. No dependencies or build step.

## Deploy

Import this repository in Vercel, choose Other, and use the repository root as the output directory.

Edits are session-only. Download Markdown documents to keep them. Example numbers are illustrative targets, not measured results.
